\# Storage Converter



\## Purpose

This program converts a storage size from gigabytes (GB) to megabytes (MB).

It was written for CS-117 Lab to practice Git and GitHub.



\## How to Run

1\. Open a terminal in this folder.

2\. Run: python storage\_estimator.py

3\. Enter the storage size in GB when asked.



\## Example

Input:

Enter storage in GB: 2



Output:

2.0 GB = 2048.0 MB
